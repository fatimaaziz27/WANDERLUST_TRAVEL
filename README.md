# WANDERLUST TRAVEL

A modern and responsive travel website designed to showcase destinations, travel packages, and travel experiences with a clean and attractive user interface.

## About

**Wanderlust Travel** is a travel website project built using **HTML and CSS**.

The website is designed to provide users with an engaging way to explore popular destinations, view travel packages, learn about the travel service, and find travel information.

## Features

* Responsive navigation bar
* Hero section with travel-focused design
* Destination search section
* Popular Destinations section
* Destination cards
* Why Choose Us section
* About Wanderlust section
* Travel statistics
* Featured Travel Packages
* Package details and pricing
* Special Offer section
* Reviews section
* Contact / Booking section
* Footer with useful links and destinations
* Font Awesome icons
* Responsive layout for different screen sizes
