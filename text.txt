New CSS Challenges

These are the things I especially want you to practice in Project 3.

1. Overlapping elements

For example, the search box can overlap the bottom of your hero.

Practice:

position: relative;
position: absolute;
2. Image overlays

Try creating a dark gradient over destination images so the destination name can sit on top of the image.

3. Badges

Create:

Use Grid for:

5. Flexbox

Use Flexbox for:

Navbar
Hero buttons
Statistics

Contact information
6. Hover effects

Try making destination cards do something when the mouse enters them.

For example:

Image zoom
Card moves slightly upward
Button changes
Overlay becomes darker/lighter

Don't copy all of these—experiment.

7. CSS Variables

Use:

:root {
    --primary: ...;
    --secondary: ...;
    --accent: ...;
    --dark: ...;
    --light: ...;
}

This should now become a normal habit.

What makes Project 3 different?

Your first projects were mainly about building sections.

Now I want you to start thinking about design systems and layout relationships:

Hero → overlapping search box → destination grid → feature cards → package cards → promotional section → testimonials → forms

Don't worry if it takes longer than the previous two projects. That's intentional.

Build it yourself first. If you get stuck, send me the specific HTML/CSS you're working on rather than asking for the complete solution. I'll help you understand the problem without taking the practice away from you.
